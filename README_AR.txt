صفحة البحث في لوحات الألياف ODB
دليل التشغيل والنشر خطوة بخطوة

تم تجهيز الصفحة بشعار stc وألوان الهوية، مع حركة مخصصة لدخول حروف الشعار وتحريكها عند مرور المؤشر. الحركة مستوحاة من الهوية وليست نسخة موثقة من الحركة الحالية للموقع الرسمي. الخط العربي المستخدم IBM Plex Sans Arabic ومرفق محليًا.

القائمة: 273,309 لوحة فريدة.
نسخة البيانات: 1 أكتوبر 2026.
مصدر البيانات: https://dolaxp.github.io/st-offers/data.js
الملف المرفق هو نفس ملف المصدر دون حذف أو تعديل اللوحات.
النتيجة تعني وجود اللوحة في القائمة فقط، ولا تؤكد استحقاقًا حاليًا من المشغل أو توافر المنافذ.

1) فك الضغط وتجربة الصفحة
- نزّل STC_ODB_Website.zip.
- في ويندوز: اضغط بزر الفأرة الأيمن على الملف واختر Extract All / استخراج الكل.
- افتح المجلد الناتج. يجب أن ترى index.html مباشرة، وبجواره style.css وscript.js وdata.js ومجلد assets.
- افتح index.html باستخدام Chrome أو Edge. لا تفتحه من داخل الملف المضغوط.
- انتظر ظهور 273,309 لوحة جاهزة للبحث.
- جرّب RYDHEAU0007. المتوقع: لوحتك موجودة ضمن قائمة العرض.
- جرّب ZZZZZZ999999. المتوقع: اللوحة غير موجودة في هذه القائمة.
- يقبل البحث أيضًا ODB: RYDHEAU0007، والحروف الصغيرة، والمسافات، والأرقام العربية.
- جميع الملفات اللازمة للعمل، ومنها الشعار والخطوط والقائمة، موجودة داخل الحزمة؛ لا يحتاج البحث إلى الموقع الأصلي بعد تنزيل الملفات.

2) إنشاء حساب GitHub
- افتح https://github.com/ وسجّل الدخول.
- إذا لم يكن لديك حساب، أنشئه وأكّد بريدك الإلكتروني.

3) إنشاء المشروع
- افتح https://github.com/new
- في Repository name اكتب: stc-odb
- اختر Public.
- فعّل Add README ليتم إنشاء فرع main فورًا.
- اضغط Create repository.
- GitHub Pages متاح للمشروعات العامة بالخطة المجانية.

4) رفع الملفات
- من صفحة المشروع اختر Add file ثم Upload files.
- افتح المجلد الذي فككت ضغطه على جهازك.
- اسحب الملفات الموجودة داخله، ومعها مجلد assets نفسه، إلى مساحة الرفع في GitHub.
- ارفع المحتويات، وليس ملف ZIP، وليس المجلد الخارجي كاملًا.
- لا ترفع ملفات assets مبعثرة في الجذر؛ يجب أن تبقى داخل مجلد باسم assets.
- تستطيع رفع README_AR.txt وASSET_SOURCES.txt وsource-info.json مع الملفات.
- ملف .nojekyll اختياري لهذه الحزمة؛ إذا أخفاه ويندوز، فلا يمنع ذلك تشغيل هذه الملفات العادية.
- انتظر انتهاء رفع الملفات كلها.
- اضغط Commit changes، ثم أكّد الحفظ على main إذا ظهر حوار إضافي.

تأكد من ظهور الملفات التالية في الصفحة الرئيسية للمشروع مباشرة:
index.html
style.css
script.js
data.js
assets/
README_AR.txt
ASSET_SOURCES.txt
source-info.json

5) تفعيل النشر
- افتح Settings من أعلى المشروع.
- اختر Pages من القائمة الجانبية.
- تحت Build and deployment اختر:
  Source: Deploy from a branch
  Branch: main
  Folder: / (root)
- اضغط Save.
- انتظر اكتمال النشر؛ قد يستغرق حتى نحو 10 دقائق.
- حدّث صفحة Settings ثم Pages، واضغط Visit site عند ظهور الرابط.
- يكون الرابط على النمط: https://YOUR-USERNAME.github.io/stc-odb/
  استبدل YOUR-USERNAME باسم حسابك الفعلي، أو استخدم الرابط الذي يظهر في Pages مباشرة.
- من تبويب Actions يمكنك متابعة اكتمال مهمة pages build and deployment بعلامة النجاح.

6) التأكد من أن الصفحة تعمل بعد النشر
- افتح رابط Visit site.
- انتظر ظهور عدد اللوحات 273,309.
- جرّب RYDHEAU0007 وتأكد من ظهور النتيجة الخضراء.
- جرّب ODB: rydheau0007 وتأكد من نفس النتيجة.
- جرّب ZZZZZZ999999 وتأكد من عدم وجود مطابقة.
- افتح الرابط من الجوال للتأكد من شكل الصفحة.
- تستطيع مشاركة رابط الصفحة بعد نجاح الاختبارات.

7) لو ظهر خطأ
404:
- تأكد أن index.html بهذا الاسم والحروف الصغيرة في جذر المشروع، وليس داخل مجلد إضافي.
- تأكد أن إعدادات Pages هي main و / (root).
- انتظر اكتمال النشر في Actions، ثم حدّث الصفحة.

الصفحة بدون تنسيق أو شعار:
- تأكد من وجود style.css بجوار index.html.
- تأكد من رفع مجلد assets كاملًا مع الحفاظ على اسمه.

تعذّر تحميل قائمة اللوحات:
- تأكد أن data.js مرفوع بجوار index.html، وأن حجمه نحو 4.65 ميجابايت.
- لا تغيّر اسم المتغير BOX_CODES داخل ملف البيانات.
- اضغط إعادة المحاولة بعد اكتمال الرفع والنشر.
- لا تعتبر هذه الحالة أن اللوحة غير موجودة؛ البحث يظل غير متاح حتى يتم تحميل القائمة.

التعديل لا يظهر:
- انتظر نجاح النشر الجديد في Actions.
- جرّب Ctrl + F5 من الكمبيوتر، أو افتح الرابط في نافذة خاصة.

8) تحديث القائمة لاحقًا
- البيانات نسخة ثابتة من المصدر وقت التجهيز؛ لا تتحدث تلقائيًا من موقع stc أو من صفحة المصدر.
- لتحديثها ارفع ملف data.js الجديد بنفس الاسم وبنفس صيغة const BOX_CODES = [...].
- استبدل الملف الموجود في GitHub عبر Add file ثم Upload files، ثم Commit changes.
- عدد اللوحات في الصفحة يتحدث تلقائيًا عند تحميل القائمة الجديدة.
- لتحديث تاريخ النسخة، عدّل عنصر time الموجود في index.html وكذلك بيانات المصدر في source-info.json.
- بعد أي تعديل سيعيد GitHub Pages النشر؛ انتظر نجاحه.

الملفات التقنية
- index.html: الصفحة.
- style.css: الألوان والتنسيق والحركة والتجاوب مع الشاشات.
- script.js: البحث والتحقق من الإدخال والاقتراحات ومعالجة أخطاء القائمة.
- data.js: قائمة اللوحات.
- assets: الشعار والخطوط ورخصة الخط.
- source-info.json: مصدر البيانات وعددها وبصمتها للتحقق.

لا تحتاج إلى تثبيت Node أو npm أو أي برنامج برمجة لتشغيل أو نشر هذه الحزمة.
